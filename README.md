# Документы аттестации

Сайт для GitHub Pages со структурой документов государственной аттестации:
9 разделов (№1–№9), в №5 и в №9 «Тәрбие жұмысы» по 3 подраздела — всего 15 категорий.

Сейчас сайт пустой. Документы и данные организации добавляются в `assets/data.js`,
файлы — в папку `files/`.

* Языки: русский и казахский (переключатель в шапке).
* Поиск по названию работает и с русской раскладкой для казахских букв.
* Прямые ссылки: `#/c/<раздел>`, `#/d/<документ>`.
